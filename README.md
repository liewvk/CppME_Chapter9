# CppME_Chapter9

This repository contains C++ sample programs for Chapter 9 of "C++ Programming Made Easy." The examples focus on functions, function parameters, return values, and basic problem-solving techniques.

## Repository Structure

- `CppME_Chapter9.cpp` — the default starter program generated by Visual Studio
- `CppME_Chapter9.slnx` — solution file for the project
- `CppME_Chapter9.vcxproj` — main project configuration
- `CppME_Chapter9.vcxproj.filters` — Visual Studio filter configuration
- `CppME_Chapter9_Example9.13/` — function example for squaring a number
- `CppME_Chapter9_Example9.18/` — demonstrates pass-by-value behavior
- `CppME_Chapter9_Example9.20/` — simple calculator using multiple functions
- `CppME_Chapter9_Example9.24/` — function returning the larger of two numbers
- `CppME_Chapter9_EXample9.23/` — function to check whether a number is even or odd

## Included Examples

### Example 9.13: Square Function
Located in `CppME_Chapter9_Example9.13/`.

This program defines a function named `square` that returns the square of an integer entered by the user.

### Example 9.18: Pass-by-Value Example
Located in `CppME_Chapter9_Example9.18/`.

This example shows that changes made to a parameter inside a function do not affect the original value in `main`.

### Example 9.20: Simple Calculator
Located in `CppME_Chapter9_Example9.20/`.

This program uses function calls for `showTitle`, `add`, and `subtract` to perform basic arithmetic operations.

### Example 9.23: Even/Odd Checker
Located in `CppME_Chapter9_EXample9.23/`.

This program defines a function that checks whether an integer is even or odd and prints the result.

### Example 9.24: Larger Number Function
Located in `CppME_Chapter9_Example9.24/`.

This example reads two numbers and returns the larger one using a function.

## Building and Running

### With Visual Studio

1. Open `CppME_Chapter9.slnx` in Visual Studio.
2. Build the solution.
3. Run the project from the IDE.

### From the Command Line

Compile the main program with:

```bash
g++ CppME_Chapter9.cpp -o CppME_Chapter9
./CppME_Chapter9
```

To compile an example individually:

```bash
g++ CppME_Chapter9_Example9.24/CppME_Chapter9_Example9.24.cpp -o Example9_24
./Example9_24
```

## Notes

This repository is intended for beginners learning C++ functions, return values, and parameter passing. Each example is designed to be simple, readable, and easy to modify for practice.
